Pair mode or advisor?

AdvisorPair mode
IdeaA cheap model works; an expensive one is asked when it gets hardTwo different models work together as equals
Second model involvedOnly when the working model asks, often neverOn every request, from the first step to the last
What it doesGives one answer: no tools, no codeProposes, argues, writes code, reviews
Who decidesThe working model aloneBoth agree on the plan
CostLow most of the time; one expensive answer when askedBoth models' full work on every request
Good forSaving money with a safety net for the hard partsQuality and speed on larger tasks that split well

This page replays a scripted example (an LRU cache for an API client) to show the flow; it does not call any model. Both modes are off by default in Forge: /pair and /advisor switch them on. Back to the README
